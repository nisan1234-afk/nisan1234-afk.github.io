# טרוול בוסטר צעד-צעד — התקנת השרת (פעם אחת, כ-10 דקות)

השרת הוא קובץ אחד: `Code.gs`. הוא רץ בחשבון הגוגל שלך, ולכן כל הגיליונות נוצרים בדרייב שלך.

## 1. יוצרים פרויקט
1. נכנסים ל-https://script.google.com ולוחצים **New project** (פרויקט חדש).
2. נותנים שם, למשל: טרוול בוסטר צעד-צעד.
3. מוחקים את מה שכתוב בקובץ `Code.gs` ומדביקים את כל התוכן של `Code.gs` מכאן.
4. שומרים (Ctrl+S).

## 2. הרשאות והכנה
1. בסרגל העליון בוחרים את הפונקציה **setup** ולוחצים **Run**.
2. גוגל מבקש הרשאות (דרייב, גיליונות, חיבור חיצוני). מאשרים.
   אם מופיע "Google hasn't verified this app": ‏Advanced ← Go to … (unsafe). זה הסקריפט שלך.
3. בדרייב שלך נוצרו עכשיו תיקייה **"טרוול בוסטר — גיליונות תלמידים"** וגיליון **"טרוול בוסטר — כל התלמידים"**.

## 3. פריסה
1. **Deploy ← New deployment**.
2. סוג: **Web app**.
3. Execute as: **Me**.
4. Who has access: **Anyone**.
5. **Deploy**, ומעתיקים את ה-**Web app URL** (מסתיים ב-`/exec`).

## 4. מחברים את המדריך
שולחים לClaude את הכתובת, או מדביקים אותה בעצמך בקובץ `tb/config.js` בשדה `api`.

## עדכון קוד בעתיד
מדביקים את הקוד החדש, שומרים, ואז **Deploy ← Manage deployments ← ✎ ← Version: New version ← Deploy**.
לא ליצור New deployment, כי אז הכתובת משתנה.

## מה נוצר לכל תלמיד/ה
- בכניסה הראשונה למדריך נוצר גיליון "טרוול בוסטר — <שם>" בתיקייה, ומשותף עם התלמיד/ה לצפייה (גוגל שולח לו/ה מייל עם קישור).
- לשוניות: **פרטים**, **FIT**, **קבוצות** (ובהמשך לשוניות לתרגילים).
- בכל לשונית: עמודה לכל יחידה. שורות: סטטוס, שלב נוכחי, מתוך, התקדמות %, מספר דוקט, הערה, התחלתי, עדכון אחרון, סיימתי.
- בגיליון המרכזי: שורה לכל תלמיד/ה עם קישור לגיליון שלו/ה, יחידות שהושלמו, היחידה והשלב האחרונים, הדוקט האחרון.

## בוט העזרה (שאלות + צילום מסך)
כפתור "💬 שאלה" בראש המדריך. התלמיד/ה שואל/ת (אפשר עם צילום), Gemini עונה ומצרף קישור לשלב במדריך.
1. מדביקים את `Code.gs` החדש ומפרסמים גרסה חדשה (כמו בעדכון קוד).
2. ב-Apps Script: ⚙️ **Project Settings ← Script Properties ← Add script property**:
   - `gemini_key` = המפתח מ-Google AI Studio (חובה).
   - `bot_daily` = כמה שאלות לתלמיד/ה ביום (לא חובה, ברירת מחדל 40).
   - `gemini_model` = לא חובה (ברירת מחדל `gemini-flash-latest`).
   - `bot_off` = `1` מכבה את הבוט (למשל ביום בחינה). מוחקים כדי להדליק.
3. גוגל יבקש פעם אחת הרשאה חדשה לחיבור חיצוני — מאשרים (Run על setup).
- כל שאלה נרשמת בגיליון "כל התלמידים", בלשונית **שאלות לבוט**.
- הבוט קורא את החומר מ-`tb2/bot-context.json` (נבנה ב-`node tb2/build.mjs` מתוך היחידות ו-`tb2/bot/knowledge.md`). מתעדכן אצלו תוך שעה.
