# נוהל בדיקת דוקטים של תלמידים — טרוול בוסטר

נוהל לבדיקה האוטומטית של Claude. רצה ברביעי ובחמישי אחרי שיעור התיירות של יב.

## קבועים
- מערכת: https://b2e-travelbooster-highschool.travelbooster.com/
- רשימת דוקטים: Find ← List of Travel Files (או ישירות `UI_NET/Booking/PaxFile/PaxFileList/Index.aspx?clear=true`)
- דוקט לפי מספר: `UI_NET/Booking/PaxFile/PaxFile.aspx?Theme=TravelBooster&dir=LTR&culture=en-us&IsFromFoc=False&paxFileNum=<מספר>`
- גיליון תוצאות: "בדיקת דוקטים — טרוול בוסטר יב" (Google Sheets, id 1gHVt5mZtKpYa7ethTV4LECzsxOuQVk2NnI_KeJo4lYs)
- תשובות לתרגילים: https://raw.githubusercontent.com/nisan1234-afk/nisan1234-afk.github.io/main/tb2/exercises.js (שדות solution ו-key)
- מדריך התלמיד (מספרי דוקט שתלמידים רשמו): גיליון "טרוול בוסטר — כל התלמידים" בדרייב של המורה

## כללים
- **צפייה בלבד.** לא לוחצים Confirm, Cancel, Amend, Voucher, Invoice, Receipt, Send או כל כפתור שמשנה דוקט.
- לא מקלידים סיסמה. אם מסך הכניסה מופיע, עוצרים ומדווחים "צריך להתחבר".
- דוקטי המורה (teacher66) ודוקטי תרגול של Claude לא נבדקים.

## שלבים
1. **בודקים חיבור:** פותחים את רשימת הדוקטים. אם מופיע מסך Welcome / Login, עוצרים.
2. **מוצאים דוקטים חדשים:** ב-List of Travel Files:
   - מנקים את Start Date (ברירת המחדל מסננת לפי תאריך הטיול, לא לפי תאריך הפתיחה).
   - מנקים את Status.
   - Open Date From = התאריך של הבדיקה הקודמת (או לפני 7 ימים). Advanced Options ← Completed Travel File = הכול.
   - Filter. רושמים את כל המספרים.
3. **מוסיפים דוקטים פתוחים מהבדיקות הקודמות:** כל דוקט בגיליון שהתוצאה שלו "לתיקון" או "בתהליך" נבדק שוב.
4. **לכל דוקט:** פותחים לפי מספר וקוראים את הטקסט של הדף (Opened by, נוסעים, שירותים, סטטוס, Accounting, Balance). אם צריך, צילום מסך של Services (העמודה S: וי ירוק = OK).
5. **מזהים את התרגיל** לפי שם הנוסע הראשי ומשווים ל-solution ול-key ב-exercises.js:
   - נוסעים: שמות, תואר (Mr./Mrs./Miss/Chd), מספר נוסעים וחדרים.
   - כל שירות: סוג, ספק (מהמערכת או בין הרים כשירות ידני), תאריך, שעה, לילות, סוג חדר, בסיס אירוח, מחיר.
   - כפילויות, שירותים מיותרים, לילות או ימים לא הגיוניים.
   - חלק ב׳ (אם התחילו): שינויים, ביטולים, אישור (SUP: מספר אישור), שוברים, חשבונית, קבלה, Balance = 0.
   - אם התרגיל לא מזוהה: בודקים רק עקביות (תאריכים, כפילויות, סטטוס, Balance).
6. **כותבים לגיליון:** שורה לכל דוקט (או עדכון השורה הקיימת):
   תאריך בדיקה · דוקט · נפתח ע"י · נפתח בתאריך · נוסע ראשי (ותרגיל) · יחידה מהמדריך (אם יש) · תוצאה · מה לתקן · פירוט השירותים.
   - תוצאה: "תקין" / "בתהליך · תקין עד כאן" / "בתהליך · לתיקון" / "לתיקון".
   - "מה לתקן": ממוספר, קצר, בעברית, עם מה צריך להיות (ספק, סכום, תאריך).
7. **מסכמים למורה בהודעה קצרה** (התראה): כמה דוקטים נבדקו, כמה תקינים, ושורה אחת לכל תלמיד שיש לו מה לתקן.

## הדוח למורה בטלגרם (מ-12.11.2026)
הבוט: "בדיקת דוקטים יב" (@nisan_tb_dockets_bot), Apps Script "בוט בדיקת דוקטים יב". לא בוט משוב.
בתפריט הבוט: "🔎 סרוק עכשיו" – מפעיל את משימת "סריקת דוקטים עכשיו" (בלי בדיקת "כבר רץ היום").
הודעה נפרדת לכל תלמיד שיש לו דוקט חדש או דוקט שהשתנה מאז הבדיקה הקודמת. דוקט בלי שינוי לא מקבל הודעה משלו.

### מבנה ההודעה (טקסט רגיל, בלי Markdown)
```
👤 <שם התלמיד בעברית> · <שם משתמש>
📁 דוקט <מספר> · <התרגיל> · נבדק <DD/MM>

❌ הטעויות
1. <מה לא נכון, קצר>
2. ...

✅ התיקונים
1. <מה לעשות, עם הערך הנכון: ספק, סכום, תאריך>
2. ...

📖 בחומר
• <נושא>: <קישור>
```
- אותו מספור בטעויות ובתיקונים (טעות 1 ↔ תיקון 1).
- כמה דוקטים לאותו תלמיד: אותה הודעה, בלוק 📁 לכל דוקט.
- תלמיד שהכול תקין אצלו: ❌ לא מופיע, רק "✅ תקין עד כאן. להמשיך:" ומה הלאה.

### ההודעה לתלמיד (WA)
לכל תלמיד מכינים הודעה קצרה בגוף שני (עד ~350 תווים):
```
היי <שם>, בדקתי את דוקט <מספר> (<התרגיל>):
1. <טעות> ← <תיקון>
2. ...
📖 לחזרה: <קישור אחד או שניים>
בהצלחה!
```
בהודעה למורה (בבוט) מוסיפים בסוף: "📲 ההודעה לתלמיד:" ואת WA, כדי שהמורה יראה בדיוק מה יישלח.

### הודעת פתיחה וסיום
- לפני ההודעות: `✈️ בדיקת דוקטים · DD/MM` + `נבדקו X · תקינים Y · לתיקון Z` (בלי כפתור וואטסאפ).
- אחרי ההודעות: שורה אחת "ללא שינוי: <שמות>" + "📊 הפירוט בגיליון".

### שמות התלמידים
EVYATAR = אביתר · YINON1 = ינון · PORAT = פורת · YIFTACH = יפתח · YEHUDA = יהודה · GERSHOM = גרשום · NAFTALI = נפתלי · EITANG = איתן ג. · EITANS = איתן ס.

## שליחה לתלמידים בוואטסאפ ווב (מ-12.11.2026)
רק אחרי אישור המורה בבוט. אף פעם לא שולחים בלי תשובה.
1. askedAt = Date.now(). post({ask:true, notify:"📲 לשלוח לתלמידים בוואטסאפ?\n1. <שם>\n2. ...\nאפשר גם לכתוב מי לא לקבל (מספרים או שמות)."}) – בהודעה כפתורי "✅ שלח לכולם" / "❌ לא לשלוח".
   ברשימה רק תלמידים שקיבלו הודעה בבוט בריצה הזו. תלמיד בלי איש קשר מאושר → "(אין איש קשר)" ולא שולחים לו.
2. חיכוי: ב-javascript_tool בלשונית BOT: await new Promise(r=>setTimeout(r,50000)) ואז post({answerCheck:true}) → "ans <ms>\n<text>". חוזרים עד 60 דקות.
   ms > askedAt → התשובה: "כולם" = כולם · "אף אחד" = אף אחד · מספרים/שמות = כולם חוץ מהם. לא ברור → שואלים שוב (ask:true).
   60 דקות בלי תשובה → post "⏰ לא התקבלה תשובה – לא שלחתי לתלמידים." וסיום.
3. וואטסאפ ווב: לשונית web.whatsapp.com (קיימת או חדשה; לא סוגרים אותה בסוף).
   לכל תלמיד: חיפוש בשם איש הקשר המאושר המדויק → פתיחת הצ'אט → לוודא שבכותרת (#main header) מופיע בדיוק השם המאושר (לא הורה) → הקלדת WA שורה-שורה עם shift+Return, ואז Return → לוודא שההודעה מופיעה בצ'אט.
   כותרת לא תואמת או לא נמצא → לא שולחים, ומדווחים.
4. בסוף: post "✅ נשלח ל: ... · לא נשלח ל: ... (סיבה)".
- רשימת אנשי הקשר המאושרים לא נמצאת כאן (ריפו ציבורי). היא בהוראות של המשימה המתוזמנת.
