# סימולטור בגרות – התקנת השרת

השרת הוא Google Apps Script עם גיליון. ההתקנה נעשית פעם אחת, ולוקחת כרבע שעה.

## 1. יצירת הפרויקט
1. נכנסים ל־script.google.com ← "פרויקט חדש".
2. שם הפרויקט: "סימולטור בגרות – שרת".
3. מוחקים את התוכן של Code.gs ומדביקים במקומו את הקובץ `Code.gs` מהתיקייה הזו.

## 2. מפתחות
"הגדרות הפרויקט" (גלגל השיניים) ← "מאפייני סקריפט" ← מוסיפים:

| מאפיין | ערך |
|---|---|
| ANTHROPIC_API_KEY | מפתח של Claude API (מ־console.anthropic.com) – לבדיקת התשובות |
| GEMINI_API_KEY | מפתח של Gemini API (מ־aistudio.google.com) – לתמלול ולהקראה |
| EXAMS_BASE_URL | https://nisan1234-afk.github.io/bagrut-sim/ |

לא חובה: CLAUDE_MODEL (ברירת מחדל claude-sonnet-5-5), GEMINI_MODEL, GEMINI_TTS_MODEL.

## 3. הרצה ראשונה
1. בוחרים בפונקציה `setup` ולוחצים "הפעלה".
2. מאשרים את ההרשאות (גיליון, דרייב, גישה לאינטרנט, טריגר).
3. ביומן (Execution log) מופיעים:
   - **מפתח המורה** – לשמור. איתו נכנסים לאתר הניהול.
   - קישור לגיליון הנתונים.

## 4. פרסום כאפליקציית אינטרנט
"פריסה" ← "פריסה חדשה" ← סוג: "אפליקציית אינטרנט":
- הפעלה בתור: **אני**
- למי יש גישה: **כל אחד**

מעתיקים את כתובת ה־Web App (מסתיימת ב־`/exec`).

## 5. חיבור האתר לשרת
בקובץ `bagrut-sim/config.js` שבאתר משנים את `api` לכתובת מהשלב הקודם. (או שקלוד יעשה את זה.)

## 6. עבודה
- אתר הניהול: https://nisan1234-afk.github.io/bagrut-sim/admin/ – כתובת השרת + מפתח המורה.
- סדר העבודה: כיתה ← הדבקת תלמידים ממשוב ← סימון התאמות ← הוספת בחינה ← פתיחת מועד ← מעקב.
- התלמידים נכנסים בכתובת https://nisan1234-afk.github.io/bagrut-sim/ עם מספר זהות וסיסמת הפתיחה של המועד.

## מורה נוסף במגמה
בעורך הסקריפט מריצים את `addTeacher` – המפתח החדש מופיע ביומן. כל מורה רואה רק את הכיתות, הבחינות וההגשות שלו.

## איך הבדיקה עובדת
- טריגר רץ כל דקה ובודק הגשות חדשות (עד 3 בכל ריצה).
- תשובות בעל פה מתומללות קודם, ואז הכול נבדק מול המחוון.
- שאלות בחירה: אם ענו על יותר מהנדרש נבדקות רק הראשונות לפי הסדר, ובמשוב כתוב כמה נקודות הפסיד. אם ענו על פחות – החסר מקבל 0.
- התוצאה: ציון, פירוט לכל סעיף, וניתוח (חוזקות, קשיים, מה חייב לשפר, תרגול מומלץ). הטקסט המלא מוכן להעתקה למט״ח באתר הניהול.
