# לוח משימות — תיאום בין קלוד (ענן) ל־Codex (מקומי)

## איך זה עובד
- **קלוד בענן** מנהל את הפרויקט וכותב כאן משימות ביקורת.
- **סקריפט מתוזמן במחשב של ניסן** (כל 15 דקות):
  1. מושך את הריפו.
  2. אם יש משימה בסטטוס `פתוח` — מריץ עליה את Codex **בקריאה בלבד**, ושומר את התשובה בקובץ `tools/reviews/<מספר>.md`.
  3. משנה את הסטטוס ל־`בוצע`, מבצע commit ו־push.
  4. אם אין משימה פתוחה — לא עושה כלום (בלי טוקנים).
- **Codex לא משנה שום קובץ באתר.** רק הסקריפט כותב: את קובץ התוצאה ואת שורת הסטטוס.
- **קלוד בענן** מושך את התוצאות, מתקן באתר, ומסמן `טופל`.
