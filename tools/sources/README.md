# חומרי מקור שחולצו

- `jer_bagrut_q.txt` — שאלות בגרות על ירושלים שחולצו מהמאגר.
- `official_T.json` — כיתובי התמונות (קרדיטים) מתוך מצגת התמונות הרשמית.
- `jer_booklet.txt`, `teacher_decks.txt` — טקסטים שחולצו מחוברת ירושלים וממצגות המורים, לבדיקת כיסוי.
- `jer01-source.txt` — חומר המקור של ירושלים 1.
- `BRIEF.md` — תדריך התכנון של החבלים.
- `council_q.md`, `council_resp.md` — שאלה ותשובה של "המועצה" (התייעצות על מבנה החומרים).
- `nlm_sources/` — הטקסטים שהועלו לנוטבוק כמקור לכל נושא (נגב, עמקים).
- `stitch_DESIGN.md` — מערכת העיצוב שסטיץ' יצר לקטלוג.

הקבצים המקוריים (מצגות, PDF, תמונות) נמצאים בדרייב, בתיקייה "אתר תירות אלוני הבשן" ובמצגת "מצגת תמונות תשפז".
